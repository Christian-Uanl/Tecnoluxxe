# Tecnoluxxe - Tienda de accesorios para celular

Proyecto base para trabajar en VS Code.

## Incluye
- Página principal
- Menú de navegación
- Sección de categorías
- Sección de productos
- Buscador
- Login de demostración
- Chat de demostración
- Botones funcionales
- Diseño responsive

## Archivos
- `index.html`
- `styles.css`
- `app.js`

## Cómo abrir
1. Abre la carpeta en VS Code.
2. Abre `index.html`.
3. Puedes usar la extensión Live Server para verla en el navegador.

## Pendiente para conectar con Supabase
El equipo de base de datos deberá proporcionar:
- URL del proyecto
- clave pública `anon`
- nombres definitivos de tablas y campos

Después se puede reemplazar:
- el arreglo local `products` por una consulta a la tabla `productos`
- el login de prueba por Supabase Auth
- el chat por una tabla de mensajes si así lo pide el proyecto

## GitHub
1. Crear un repositorio.
2. Subir esta carpeta.
3. Cada integrante trabaja en una rama o realiza commits pequeños.
